GETTING STARTED

Bring the whole conversation.

  1. Run node build-encrypted.mjs locally and choose your password.
  2. Publish only the generated docs folder. Keep the original exports out of the published repository.
  3. Unlock with your password. Search, replies, sender alignment and date navigation work as usual.

The password decrypts the archive in your browser. It is never uploaded or saved. Media decrypts when shown. Chats and manual imports are kept only for this session.

Use Lock archive or reload the page when finished. Keep your original export and password as backups; there is no password recovery.
